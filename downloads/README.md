# VTLOsint — downloads

| File | For | How to use |
| --- | --- | --- |
| [`VTLOsint.apk`](VTLOsint.apk) | Android 8.0+ | Download on the phone, open it and allow installing from this source. |
| [`VTLOsint-web.zip`](VTLOsint-web.zip) | PC (Windows, macOS, Linux) | Unzip, then open `VTLOsint-web/index.html` in Chrome, Edge or Firefox. |

The web app is also in [`../web/dist`](../web/dist), ready to open or to host on any static server
(GitHub Pages included). Served over `http(s)`, it can be installed as a desktop app from the browser's
address bar and keeps working offline.

Both are rebuilt from the cheat sheet: `README.md` and `awesome-article.md` are parsed at build time,
so every listed tool is in both apps. A short animated guide in French is shown at first launch.

> Use these tools legally and ethically, only on targets you are authorized to investigate.
